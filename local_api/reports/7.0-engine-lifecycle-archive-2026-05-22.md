## 3. 修改摘要

### T2 — Schema 加固（started_at / locked_at）

| 文件 | 修改内容 |
|------|----------|
| **`database.py`** | SCHEMA_SQL 中 `sync_state` CREATE TABLE 新增 `started_at TEXT, locked_at TEXT`；新增 `_run_migrations(conn)` 函数安全执行 ALTER TABLE ADD COLUMN（try/except sqlite3.OperationalError）；`get_db()`/`init_db()`/`reset_db()` 均触发迁移 |
| **`services/sync_state_service.py`** | `transition_sync_state()` 中 `pending→in_progress` 时写入 `started_at`（仅首次，`existing["started_at"] is None` 守卫），`locked_at` 每次进入 in_progress 都更新；`create_sync_state()` 同步新增列 |
| **`sync_engine.py`** | `_handle_timeouts()` 超时计算从 `updated_at` 改为 `started_at`，`started_at is None` 时 fallback 到 `updated_at`；SELECT 排序仍用 `updated_at ASC` 保持公平轮转 |
| **`tests/test_state_transitions.py`** | 新增 `TestSyncStateTimestamps` 类（3 个测试）：首次设置、多次不覆盖、NULL 兜底 |

### T1 — Engine 生命周期集成

| 文件 | 修改内容 |
|------|----------|
| **`config.py`** | 新增 `SYNC_ENGINE_AUTO_START = False`（默认不自动启动） |
| **`sync_engine.py`** | 新增 `self._lock = threading.Lock()`；`start()` 用锁保护保证幂等；`stop()` 双锁模式（锁内设 event → 锁外 join → 锁内清理）避免死锁；`_run_loop()` 内 `try/except Exception` 保护单次扫描异常不拖垮整个线程 |
| **`main.py`** | 模块级 `engine = SyncEngine()` 实例；`lifespan()` 中 `if config.SYNC_ENGINE_AUTO_START: engine.start()`；shutdown 时始终 `engine.stop()` |

### T3 — Sync Engine 管理 API

| 文件 | 修改内容 |
|------|----------|
| **`models.py`** | 新增 `SyncEngineStatusResponse`（running, status, scan_count, last_scan_at, queued_pending）和 `SyncEngineStatsResponse`（total_scans, total_processed, success_count, failed_count, success_rate, failure_distribution） |
| **`sync_engine.py`** | 新增 `_scan_count` / `_last_scan_at` 计数器和 `scan_count` / `last_scan_at` / `daemon` 属性 |
| **`main.py`** | lifespan 中设置 `app.state.engine = engine` 供路由访问 |
| **`routers/system.py`** | 新增 4 个端点：|
| | • `POST /api/system/sync-engine/start` — 启动 engine，返回 `{"status": "started" \| "already_running"}` |
| | • `POST /api/system/sync-engine/stop` — 停止 engine，返回 `{"status": "stopped" \| "not_running"}` |
| | • `GET /api/system/sync-engine/status` — 返回 running/status/scan_count/last_scan_at/queued_pending |
| | • `GET /api/system/sync-engine/stats` — 从 sync_logs 表聚合统计（含 failure_distribution 按 error_code 分组） |
| **`tests/test_api.py`** | 新增 13 个测试（4 个测试类覆盖 start/stop/status/stats 的幂等性、空数据、认证场景） |

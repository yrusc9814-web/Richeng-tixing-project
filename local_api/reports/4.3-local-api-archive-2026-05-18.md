## 1. 4.3 目标

在本地实现 FastAPI + SQLite 测试链路，验证：

- Bearer Token 认证
- 输入校验（status 枚举 / SQL injection / Shell injection / 越权字段）
- Content-Type 校验（仅 body 存在时）
- 时区统一 Asia/Shanghai +08:00
- 15 用例 API 验证脚本

**约束**：不接入外部 API（Apple / Weather / WeChat），不配置 LaunchAgent / Keychain。

### 4.1 Bug 2 深入说明

初查时 `_iso_now()` 代码已正确（`datetime.now(ZoneInfo("Asia/Shanghai")).isoformat()`），但验证仍输出 `Z`。根因：旧 uvicorn 进程（PID 9776）占端口 8100，`taskkill` 杀了错误的 PID，修复代码未能被服务加载。重启正确进程后输出 `+08:00`。

## 10. 残余风险

|------|------|------|
